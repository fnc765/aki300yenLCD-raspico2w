    流れる文字 message / message_url / show_settings

    文字の後ろに ◆ 設定 http://…/ コード 123456 ◆ を毎周流します。 入れている間は、LCD を見られる人なら誰でも、同じ Wi-Fi からこのページで設定を変えられます (コードがずっと見えているため。0.5.0 でも、起動後 1 分の案内が出ている間は同じでした)。 来客や人通りから LCD が見える場所では外してください。外しても「LCD にコードを表示」で 1 分だけ出せます。

    表示 layout / slide / status / scroll

    大きく表示すると、時計・天気は右側へ移ります。履歴は起動中に蓄積し、再起動で消えます。短い期間は5秒、6・24時間は2分の集計値です。画面の見本の電力・グラフはサンプル値です。

    状態 3 行 (Wi-Fi / 版数 / OTA) の表示

    写真 images=0 / 16

      並べた順に切り替わります (ドラッグか ↑↓ で並べ替え)。「使う」を外した写真は SD に残したまま出しません。追加する写真は 400×96 に切り抜いて 24 bit の BMP (115,254 バイト) にして送ります。

      変更はありません

      アクセスコード

      設定を変えるには、LCD に出ている 6 桁のコードが要ります。コードは端末を起動するたびに変わります。

      確認

      写真を切り抜く (400×96)

      ドラッグで位置、拡大はスライダー / ホイール / 2 本指。
