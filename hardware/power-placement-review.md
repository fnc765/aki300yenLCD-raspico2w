# 電源部の部品配置レビュー（2026-09-08、2026-09-16更新）

変更前を `f21348d` にコミットした後の配置変更。基板は100×52 mm、上辺に既存の切り欠きを持つ。Pico/U1、LCD/J1、四隅の取付穴、Pico内の禁止領域、回路図・BOM・部品値・パッドのネット割当は保持した。電源関係24部品（コネクタ・テストポイント含む）を、ユーザー指定の赤枠領域だけへ移した。銅箔配線はまだ行っていない。RV1はユーザーが手動調整した `(53.5, 3.76) mm` を保持した。

## 調査と採用した方針

- [onsemi AN920、p.21](https://www.onsemi.com/pub/Collateral/AN920-D.PDF)：大電流ループを短く太くし、低電流の帰還／制御GNDとスイッチングGNDの戻りを入力コンデンサまで分ける。分圧抵抗をICへ近づける。
- [TI SLVA773、p.2–4](https://www.ti.com/lit/an/slva773/slva773.pdf)：昇圧では整流器・出力コンデンサ・スイッチのループを優先する。L1とSWノードを小さくまとめ、FBを離す。これは別ICを用いた一般的な昇圧配置指針なので、MC34063の実際の端子・外付けダイオードに読み替えた。
- [TI MC34063A、p.17](https://www.ti.com/lit/gpn/mc34063a)：帰還と入力デカップリング経路を短くする。掲載配置例は降圧であり、その形を昇圧基板へそのままコピーしていない。
- [秋月電子 A295-CTRPB-1（116895）](https://akizukidenshi.com/catalog/g/g116895/)：5V入力を小型・低価格の電源専用Type-Cメスコネクタへ変更し、公式寸法図に基づく専用スルーホールフットプリントを作成した。基板左端からケーブルを挿せる向きでJ2を左外周へ配置した。
- [秋月電子 USB Type-C給電資料](https://akizukidenshi.com/goodsaffix/powered_by_type-c.pdf)：116895は内部にもCC1/CC2接点がなく、Type-C電源側からは給電されない。R17/R18を削除し、USB-A電源とA-to-Cケーブルで5Vを供給する前提を回路図・BOMへ明記した。

2026-09-16の赤枠制約更新では、部品のF.CrtYd全体が `X=0.4..26.6 mm, Y=0.4..51.6 mm` に入ることを必須条件にした。上辺切り欠き `X=25.0..26.6 mm, Y=0..10 mm`、固定したH1/H2/J1、および対象部品同士を障害物として扱い、数理配置では0.20 mm、最終読み戻しでは0.15 mmのコートヤード余白を確認した。U3/D4/L1/C8の昇圧ループ、D6/D7/C9/C11の反転電源経路、USB-CのVBUS/GND経路を重み付きで評価し、探索結果をKiCad DRCと画像で再確認して採用した。

アキシャル抵抗R7/R8/R9/R10/R11/R16はすべて縦置き、DO-41ダイオードD4/D6/D7もすべて縦置きに変更した。TP1～TP4は下外周に1列でまとめ、13V8端子J3は左外周へ配置した。密集領域の参照番号とD4/D7の極性文字はF.Fabへ移し、シルク重なりを避けた。

数値はパッド中心の直線距離。実配線長や電源性能の測定結果ではない。

小型USB-Cコネクタを含む24部品を赤枠内へ収めた。J2～C6のVBUS/GND直線距離は11.240/11.115 mm、D6再配置でC9～D6は24.818 mmから5.004 mmへ短縮した。今後の配線ではJ2～C6とC6 GNDを太く引き、C8/U3の電流をR10/C7の細い帰還配線へ流さない。FB検出はC8の出力端子から独立して引き、R7検出線も抵抗端子から取り出す。SW配線の下／近傍へRGBやFBを通さない。この配置は未配線の機構・部品配置案であり、電源性能の実測完了を意味しない。

## 検証と残件

- 2026-09-16 小型USB-C・縦置き更新後の最終ERCは0件。DRCは14件（既存RF禁止領域とH3の干渉エラー1、警告13）。未配線は別枠で85件。
- 対象24部品のコートヤードが赤枠内に完全に入り、上辺切り欠き・固定部品・対象部品同士とのコートヤード干渉が0件であることを、配置スクリプトの読み戻し検証で確認した。
- C9の＋端子を`+13V8`から`SW_NODE`へ修正し、回路図・基板・生成スクリプトを一致させた。出力ネットリストでもC9 pin 1、D4 pin 2、L1 pin 1、U3 pin 1が同じ`SW_NODE`に属することを確認した。
- D5/D8を3mm砲弾型THT LEDへ変更した。D5は秋月電子 111635（OSG5TA3Z74A、緑）、D8は111577（OSR5JA3Z74A、赤）で、フットプリントはともに`LED_THT:LED_D3.0mm`。C7は秋月電子 131236（RDE5C1H471J0P1H03B、470pF、50V、C0G、±5%、リード間隔2.5mm）をBOMへ反映した。
- J2は秋月電子116895（A295-CTRPB-1）へ変更し、J2 pin 1=`+5V`、pin 2=`GND`を確認した。CC端子は部品内部にも存在しないためR17/R18を削除した。USB-C電源とのC-to-C接続には使用できず、USB-A電源とA-to-Cケーブルを使う。
- 2026-09-16対象部品について、基板上のパッド番号とネット割当をKiCad読み戻しで確認した。
- 全電源部の短絡・クリアランス・コートヤード干渉は0件。未配線85件は配線前の状態。
- 既存のH3とPico RF禁止領域の干渉1件は残る。警告13件はライブラリ不一致9件、シルク端2件、シルク重なり1件、シルクと銅箔1件。短絡・クリアランス・コートヤード・銅箔端・ソルダーマスクブリッジのエラーは0件。製造用完成データではない。
- 基板外にあった下書き注記と古い区切り線はDwgs.Userへ移した。文字・図形の内容は残した。

## 再現と出力

`place_power_stage.py`をKiCad 9付属のpython.exeで実行する。通常の更新はこのスクリプトの固定配置を使い、古い全体生成スクリプトから基板全体を再生成しない。`--output`で候補を指定でき、`--report`で距離・不変条件の検証記録を出力できる。

`optimize_power_placement.py`は候補比較用。赤枠、上辺切り欠き、固定部品、コートヤード、重要な端子間距離、SW配線と感度の高い部品の交差を評価した。最終配置はDRCと画像確認を経て固定したもので、探索スコアだけで承認していない。

`review/power-placement-2026-09-08/`に最終DRC/ERC、検証JSON、KiCad純正SVG、その無加工ラスタライズPNG、純正3D PNGを保存。画面取得機能がWindows ACLエラーで起動できなかったため、画像はGUIスクリーンショットではなくKiCad公式出力。3Dモデルが未登録の部品は3D画像ではパッドのみになるため、実装外形は2D図で確認する。

2026-09-16更新分のERC、DRC、ネットリスト、KiCad純正SVGおよびPNGは`review/power-update-2026-09-16/`に保存した。
